
# 🚀 Yagami AI - Assistant Virtuel

Bienvenue sur le dépôt officiel de **Yagami AI**, un assistant virtuel intelligent inspiré des meilleures interfaces comme ChatGPT et Gemini. Cette application est conçue avec **Streamlit** et propulsée par les modèles de langage open-source les plus performants.

## ✨ Fonctionnalités
- 🎨 **Interface Moderne** : Thème sombre épuré, bulles de discussion fluides et barre de saisie fixe en bas de l'écran.
- ⚡ **Réponses Instantanées** : Connecté à une API ultra-rapide pour répondre à toutes les questions du quotidien.
- 📱 **Responsive** : Fonctionne parfaitement sur ordinateur, tablette et smartphone.

## 🛠️ Installation et Lancement en Local

Si tu souhaites faire tourner Yagami AI sur ton propre ordinateur, suis ces étapes :

1. **Cloner le projet** :
   ```bash
   git clone https://github.com
   cd yagami-ai
   ```

2. **Installer les outils nécessaires** :
   ```bash
   pip install -r requirements.txt
   ```

3. **Lancer l'application** :
   ```bash
   streamlit run main.py
   ```

## 📦 Technologies Utilisées
- [Streamlit](https://streamlit.io) - Pour l'interface utilisateur web.
- [Hugging Face Inference API](https://huggingface.co) - Pour la connexion au modèle d'IA (Qwen 2.5).
- Python 3.x
